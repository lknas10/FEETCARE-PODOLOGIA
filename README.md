# Feet Care — Podologia Sudoeste

Landing page da Feet Care — Podologia & Spa, no Sudoeste/Octogonal, Brasília — DF. O site apresenta os serviços da clínica e direciona os visitantes ao WhatsApp para agendamento.

## Estrutura

```text
FEETCARE-PODOLOGIA/
├── index.html              # Estrutura e conteúdo da página
├── styles.css              # Estilos, temas e responsividade
├── script.js               # Animação do hero e controle do vídeo
└── assets/
    ├── logo.png
    ├── imagem-cuidado.png
    └── video-principal
```

## Tecnologias

- HTML, CSS e JavaScript puros
- Google Fonts (Albert Sans e Young Serif)
- Layout responsivo, tema automático e respeito à preferência de reduzir movimento

## Como visualizar

Abra `index.html` no navegador. Não é necessário instalar dependências ou executar um processo de build.

## Onde editar

| Alteração                                 | Arquivo      |
| ----------------------------------------- | ------------ |
| Textos, serviços, contatos e links        | `index.html` |
| Cores, layout e responsividade            | `styles.css` |
| Animação de rolagem e reprodução do vídeo | `script.js`  |
| Logo, imagem e vídeo                      | `assets/`    |

Os arquivos de mídia são carregados diretamente de `assets/`; não há imagens ou vídeos em base64 no HTML.

## Informações para confirmar antes de publicar

- Horários completos de atendimento;
- validade e condições do desconto de 5%;
- nota média e quantidade de avaliações informadas no site.
